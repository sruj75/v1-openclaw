# Use outcome-first cognitive intervention with embodied technique

Intentive's cognitive behavior should be designed around performance outcomes,
not conversation quality, visible frameworks, or sensor-driven optimization. The
Execution Companion builds relational context through repeated natural
conversation, handoffs, and observed support history, then uses embodied
real-time performance psychology to help the user produce results they could not
reliably produce from their previous state. The user should experience the
"after" effect: walking out of the interaction more capable, agentic, clear, and
able to act.

**Considered Options**

- Conversation-first companion: feels human, but risks making a good chat the
  end product instead of using conversation to create results.
- Visible psychological framework: easier to explain and test, but makes the
  experience feel clinical, analytical, or like a worksheet.
- Sensor/event-based cognitive optimization: aligns with some quantified-self
  research, but pulls Intentive away from the Wendy Rhodes model and toward
  passive sensing plus nudges.
- Outcome-first embodied intervention: preserves the human conversational
  surface while keeping the product accountable to performance outcomes.

**Decision**

Use outcome-first embodied intervention.

The companion should use psychological technique through timing, questions,
language, calibrated pressure, restraint, memory, and follow-through rather than
explaining the technique to the user. Relational context and performance
intimacy earn the right to intervene; real-time performance psychology makes the
intervention effective; the performance outcome is why the interaction matters.

**Consequences**

Prompt work should optimize for whether the user exits the interaction better
able to perform, not whether the agent explained its method well. Product copy
and runtime behavior should avoid exposing cognitive labels unless the user asks
how the companion is thinking. Proactivity should stay relational and
contextual, built from prior conversations and handoffs, not biometric sensing,
passive surveillance, or generic event-based nudges.

This decision does not remove the need for prompt operationalization. The
cognitive method still needs concrete cues, decision rules, examples, and trace
review. It only decides that those mechanics belong under the hood, while the
user-facing experience should feel like a precise human intervention that leads
to results.
